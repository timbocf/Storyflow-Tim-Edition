Walkthrough: Actor Reference Sheet

The workflow from Cutscene Artist's "Create Actor Reference with Storyflow" video, using the bundled Photo to Actor sample project: start from one photo, end with a multi-view sheet of the same person in a chosen costume — the kind of sheet you reuse to keep a character consistent (or crop for LoRA training).

Before you start

  1. Install the Pipeline once. iPad: put the Pipeline .js file in Files → On My iPad → Draw Things → Scripts, then relaunch Draw Things. Mac: ~/Library/Containers/com.liuliu.draw-things/Data/Documents/Scripts/. (Alternative from the original readme: create a new script inside Draw Things, select-all and delete its boilerplate, paste the whole file in, save.)
  2. Set up Draw Things first. Load the model you want (the video's workflow uses a Qwen image/edit setup) and dial in your usual settings. The Photo to Actor project contains no Config instruction, so it inherits whatever Draw Things is currently set to — model, steps, everything.
  3. Have a photo ready in a place the image picker can reach.

The project's list, step by step

#InstructionWhat happens and why
1–2Clear Image · Clear MoodboardClean slate — no leftover canvas or references.
3Size 1024×1024A square working canvas for the face stage.
4SwapThe run pauses. You pick your photo. This is the raw material everything else derives from.
5Face ZoomThe view zooms onto the detected face, so the next step works on a close-up instead of a whole scene.
6InterrogateThe answer model describes the face — the project's question asks for a brief sentence covering gender, age, hair texture, and similar identifying traits. The answer lands in the bucket. This text is the character's identity for the rest of the job.
7ApproveThe run pauses again. The description is shown in an editable box. Fix it here — anything wrong in this sentence will be faithfully reproduced in the render. Whatever you leave in the box is the bucket going forward.
8Canvas to MBThe (zoomed) face photo goes onto the moodboard as a visual reference, so the edit model can see the person as well as read the description.
9–10Clear Image · Size 2048×1152Fresh canvas at sheet size — wide, for a close-up plus full-body views side by side.
11–12Concat + WildcardThe bucket gets "The Costume is" plus one card picked at random from the project's costume list. Re-run the project for a different outfit, or edit the cards to dress the character yourself.
13ApproveOne more pause to check/edit the combined description + costume text before it renders.
14PrefixBolts the sheet instructions onto the front of the bucket: multiple views of the same actor, same costume, on a white background.
15PromptRenders. Lays out the sheet: close-up face at left, three full-body views at right. The moodboard face reference plus the edited description are what keep it the same person.

Running it

  1. Load Photo to Actor in the Editor (or rebuild the list from the table above) and Export to Clipboard.
  2. In Draw Things, run StoryflowPipeline, paste into Menu A.
  3. Preflight: check the render count is 1, and when the answer-model menu appears pick Qwen 3.5 4B if your device can run it (it's the recommended one; it doesn't run on every device — fall back to the default if it misbehaves).
  4. Press Start Pipeline and stay nearby for the two pauses (Swap, then the two Approves).
  5. The finished sheet is on the canvas. Save it from Draw Things — or add a Save Full instruction at the end of the list if you want it filed to Pictures automatically every run.
Make it yours: replace the costume Wildcard's cards with your own list, add a Config item at the top to pin the model/settings instead of inheriting Draw Things' current state, and Save Project under a new name. Every future actor is then: run, pick photo, approve description, done.

The other two sample projects, decoded

CharacterSheet 3×2 (1920×1280)

A loop of 8 that builds each prompt entirely from Concat glue plus four shuffle Wildcards (creature type, clothing, accessory, coat description), then a single Prompt describing a 3×2 grid of camera views. The view descriptions are @ prompt triggers (@closeup, @profile, …) defined in the project's Prompt Triggers tab, and a full Config item (Krea 2 Turbo with tiled decoding) pins the setup. Its Note says it's for making character sheets to crop for training data. Same pattern as the minimal variety loop, scaled up.

Juxtapolooza Dark Art

The Sweep showcase: a Config for an SDXL model, XL Magic (3/4/7), a persistent Negative, then a loop of 10 where a Sweep steps stochasticSamplingGamma upward pass by pass while the prompt is assembled from alternating Concat glue words ("by", "of", "in the style of") and shuffle/random Wildcards of mediums, artists, scenarios, and subjects. A good study in combining several independent pickers in one loop.
