Editor Guide

The Editor is a single web page. It never touches Draw Things — its whole job is producing the instruction text the Pipeline runs. This page walks every part of it.

The header

  • Project name — type it into the title field. It's used in the Preview header and as the export file name.
  • Documentation — this wiki.
  • Tim Edition Pipeline — downloads the fixed Pipeline script from this site, ready to install into Draw Things.
  • Storyflow Online / Pipeline Plugin / GetConfigPro — links to wetcircuit's original site and downloads. GetConfigPro is her separate helper for capturing Draw Things settings as Config items.
  • Theme picker (🍧 day / 🌙 night / ⚡ cyberpunk) — cosmetic only. Your choice is remembered between visits; it is the only thing the Editor remembers on its own.

The action bar

ButtonWhat it does
🆕 New ProjectClears everything and starts with a single empty Note.
💾 Save ProjectDownloads the project as a .json file — your editable source, including the instruction list and all four shorthand libraries below. Keep this file; the export alone can't be re-edited.
📂 Load ProjectLoads a project .json back into the Editor.
⬇️ Export to PipelineDownloads the instruction list as a .txt in Pipeline format.
📋 Export to ClipboardCopies the same export text instead. In the Tim Edition it tries the modern clipboard, then a legacy method, then shows a manual-copy popup — and the button reports whether it worked (see Tim Edition Changes).
No autosave, no undo. Closing the tab loses unsaved work, and there is no undo for a deleted item. Save Project early and often.

The instruction list

Your project is the numbered list in the middle of the page. Each item shows a drag handle (⋮⋮), its type, and its fields. Drag the handle to reorder — the Editor has custom touch-drag handling so this works on iPad — or use the item's ⬆/⬇ buttons. The ⧉ copies the item, ❌ deletes it, and ▾ collapses it to its header row. Each item's left edge is color-banded by family (prompt blue, video purple, mask green, file orange, loop red, canvas teal, moodboard gold). Items inside a Loop are indented under it, and a Loop problem (an End Loop with no Loop, or a Loop never closed) is flagged on the item and named in Preview. Above the list, Quick add inserts a complete Video Scene (Add Text + Length from Dialogue + Prompt), a Still Image (a Prompt), or a Load Image in one tap. Load Image, Load Mask, and Add to Moodboard items have a 🖼️ Pick… button that fills in a picture's file name from the photo/file picker and shows a thumbnail — the picture itself must be a PNG in Draw Things' Pictures folder under that name (save it there from Draw Things first; a Photos-app picture has no path of its own), and the action bar shows a live 🎬 Renders count — if it's zero, a banner explains why and offers a one-tap fix, instead of the Pipeline reporting "number of renders: 0" later.

The tray (adding instructions)

The tray is where new instructions come from. In the Tim Edition it docks as a permanent column on the left by default; the ◀ Left / ▼ Bottom buttons in its header move it back to the original bottom bar, and the choice is remembered. It has three sizes — click its toggle to cycle collapsed / medium / full (in left mode, collapsed folds it to a slim rail). A "find an instruction…" box at the top filters the buttons by name. It contains:

  • The speed rail — six everyday items you can drag straight into the list: Note, Clear Image, Size, Prompt, Frames-by-Dialog (💬), Crop.
  • The full button grid — every instruction, grouped by category (Prompts / Img Vid / Config / Canvas / Moodboard / Mask / Layers / Loop), with filter tabs to show one category at a time. Click a button to append the item, or drag it into place.

Button colors match the categories, which helps once a list gets long.

The tabs and the four shorthand libraries

The Instruction List tab is the main view. The other tabs open as panels over it. Four of them are libraries of reusable shorthand that get expanded at export time — and telling them apart is the most confusing part of Storyflow, because three of them look similar:

LibrarySymbolUsed inHow it expands
Prompt Triggers@namePrompt, Concat, Prefix, Negative textDefine @hero once as a long description; type @hero anywhere in prompt text and the full description is substituted at export. Triggers can contain other triggers — expansion repeats until nothing changes.
Wildcards (Editor kind)$namePrompt textOptions separated by |. At export, one option is picked at random, once, and that fixed text is exported — re-export to re-roll. $name[2] picks option 2 specifically. Not the same thing as the Wildcard instruction, which picks at runtime in Draw Things (see Wildcards, Sweeps & Loops).
Config Shortcuts#nameConfig itemsStores a whole chunk of Draw Things settings JSON. A Config item can be just #16:9 or #wan_i2v; at export the full settings are swapped in. Change the shortcut once and every Config item using it changes — the "set it in one place" tool.
JSON Poses#nameJSON Pose itemsStores OpenPose skeleton JSON under a name. Yes, same # symbol as Config Shortcuts — which library applies depends on which kind of item you're typing in.
Careful with cycles: if a trigger's text (directly or through others) contains itself, expansion can't finish cleanly. The original Editor looped forever and hung the tab; the Tim Edition caps expansion (10 passes / 200k characters) so the tab survives, but the output will be garbage. Keep trigger definitions one-directional.

The Preview tab

Preview shows the project name, how many Prompt instructions you have, total video running time for all three families (Wan / LTX / MiniMax H3), and a numbered, readable rendering of the list with @ triggers already expanded. In the Tim Edition it also expands # config and pose shortcuts and shows $ wildcards as their first option (the real export rolls randomly, so Preview stays stable while you type). Wildcard and Sweep items show only their first card — their real pick happens during the run.

Preview also validates JSON as you work: Config/Pose items (after shortcut expansion) and form-builder items with bad JSON get a red outline and a ⚠ flag in the list, Preview names the offending item numbers, and both export buttons refuse to export until it's fixed.

Working comforts (Tim Edition): every item shows a one-line description under its label and has a ⧉ duplicate button next to ❌. List changes — add, delete, duplicate, reorder, Load, New — can be undone with the ↩️ Undo button or Ctrl/Cmd+Z, up to 30 steps (typing inside a field keeps that field's own undo). The project also autosaves in your browser as you work and restores itself when you reopen the page.
