Instruction Reference

Every instruction the Editor can add, grouped the same way as the tray. Instructions run top to bottom; most only prepare — a Prompt instruction is what renders. Terms used below: the bucket is the concat text being built up; the answer model is the vision model chosen at preflight (see How It Works).

Prompts

InstructionWhat it does
PromptRenders. Final prompt = everything in the bucket + this item's own text. Empties the bucket afterward, ready for the next render.
ConcatAdds its text to the bucket. For building one long prompt out of labeled sections: subject in one Concat, clothes in the next, style in the next.
WildcardAdds one card from its list to the bucket, picked at runtime by its mode. See Wildcards, Sweeps & Loops.
InterrogateSends the current canvas image to the answer model with your text as the question ("Describe this actor: gender, age, hair…") and adds the answer to the bucket. The photo-to-description step in the actor sheet walkthrough.
EnhanceSends your instruction text plus the current bucket to the answer model as a rewrite job ("turn this into a detailed image prompt…"). The answer replaces the bucket. Pair with Prefix afterward to bolt your style words back on.
PrefixSticks its text onto the front of the bucket. Made for after Enhance — LoRA trigger words and style terms go first.
Get PromptCopies the prompt text currently sitting in Draw Things' own prompt box into the bucket. Tim Edition: it adds to the bucket (the original silently replaced the bucket — fixed, see Tim Edition Changes).
NegativeSets the negative prompt from this point on. It sticks for the rest of the run until another Negative changes it.

Img / Vid

InstructionWhat it does
Clear ImageClears the canvas and control layers. Moodboard and mask survive.
Save FullSaves the whole canvas as a PNG into your Pictures folder (path you type, e.g. myProject/image.png). Save paths must end in .png, the folder must already exist, and an existing file with the same name is overwritten without asking.
Save AreaLike Save Full, but saves only the visible render area instead of the whole canvas.
LoadLoads a PNG/JPG/WebP from Pictures onto the canvas, clearing it and scaling the image to the current render size.
SwapPauses the run. Pops up an image picker so you choose or replace the canvas image by hand; an "ignore swap" switch keeps what's already there.
Frames — WanSets the frame count for the next video render: steps of 4+1 (1, 5, 9 … 128) at 16 fps.
Frames — LTXSteps of 8+1 (1, 9, 17 … ~1000) at 25 fps.
Frames — H3MiniMax H3: steps of 17 with an offset of 5 (5, 22, 39 …) at 24 fps; slider at 0 means 1 frame. Details on the Video Frames page.
Frames by Dialog 💬Counts the words inside "quotation marks" in the bucket and sets the frame count from a speaking pace. Tick its Generate box and it also renders immediately using the bucket as the prompt, so no Prompt item is needed. Full rules on the Video Frames page.

Config

InstructionWhat it does
ConfigThe power tool. Paste any chunk of a Draw Things settings JSON — full or partial. Those settings are merged in and apply from the next render onward. This is where model choice, LoRA stacks, sampler, and steps live. A Config item can also be just a #shortcut (see Editor Guide). Unlike Size, Config does not resize the canvas by itself.
SizeFriendly width/height fields (rounded to multiples of 64, minimum 128). Resizes the canvas immediately.
Size x2Doubles width and height, keeping the current visible image pasted in — stage one of an upscale: double the canvas, then let an upscale model re-render into it.
SweepThe settings cousin of Wildcard: names one setting (e.g. steps) and steps it through a list of values, one per hit, by mode. No range checking at all — values are trusted completely. See Wildcards, Sweeps & Loops.
High-res FixA friendly form for the four hires-fix settings (on/off, width, height, strength) instead of raw Config JSON.
In-paint ToolsA friendly form for inpaint settings: strength, mask blur, mask blur outset, and the keep-original-after-inpaint switch.
XL MagicSDXL only. Three numbers 1–8 (Original / Target / Negative) that pick a matched set of latent sizes from a fixed table (256×192 up to 2048×1536). SDXL renders sharper when those three sizes follow a matched pattern; this picks the pattern without typing six numbers. Low values can suit hand-drawn styles; a low-to-high spread suits photos. Ignore it for Flux/Krea/Qwen models.

Canvas

InstructionWhat it does
Face ZoomRuns Draw Things' face detection; if it finds a face smaller than about 65% of the canvas height, it zooms and re-centers the view on it (moving the render area, which is how the next render becomes a close-up). Falls back to a mild 1.2 zoom near the top-left if detection fails or the face is already big. Only the first face counts.
Ask ZoomThe same zoom, but the answer model finds a named thing ("a hat") and returns a box around it. Useful for objects Face Zoom can't detect.
Move ScaleSets the canvas view position (X, Y) and zoom (Scale) directly. The multi-panel mover: paired with Matte, this slides a big canvas around under a fixed render window.
Adapt SizeResizes the canvas to fit the image currently on it, capped at your Max Width / Max Height, snapped to multiples of 64, view recentered. For normalizing odd-sized loaded photos before working on them.
MatteFills the canvas with a solid color foundation layer (black, white, red, green, blue, yellow, cyan, magenta). Used under Move Scale for panel layouts.
Crop ImageTrims the image down to the visible render area and reloads it as the whole canvas.
Remove BKGDUses Draw Things' background detection to make the background transparent (shows as flat grey on canvas; exports as transparency when saved as PNG).

Moodboard

The moodboard is Draw Things' reference-image board — edit-style models look at these images as visual references.

InstructionWhat it does
Clear MoodboardEmpties the board.
Canvas to MBCopies the visible canvas onto the board as a reference.
Add MBLoads an image file from Pictures onto the board.
Remove MBRemoves a board image by index number (indexes start at 0).
MB WeightsA weight 0–1 for each board slot (slots 0–7). Per the original doc, modern edit models treat any weight above 0 as "use it" and 0 as "ignore it"; older models are more sensitive to the exact value.
Add ⓘ MBLoop-only: each loop pass takes the next image from a Pictures folder and adds it to the board. Cycles back to the start if the loop outlasts the folder.

Mask

The mask is the black/white "only repaint here" layer used for inpainting. Once set, it is handed to every render until cleared.

InstructionWhat it does
Clear MaskClears the Pipeline's mask. (Known seam: it does not clear a mask that was loaded into Draw Things' own mask layer from a file — see known issues.)
Load MaskLoads a mask image from Pictures into Draw Things' mask layer.
Foreground / Background MaskAuto-detects that part of the image and makes it the mask.
Body MaskBuilds a mask from body-part checkboxes (upper body / lower body / clothes / neck) plus an "extra" grow-by-pixels amount. The clothing-swap-and-inpaint workflow. If detection fails, the mask ends up empty.
Load ⓘ MaskLoop-only: next mask file from a folder each pass — kept in step with Load ⓘ Image for batch processing a folder with matching masks.

Layers

Draw Things keeps extra layers alongside the canvas: a depth layer and a pose layer.

InstructionWhat it does
Extract DepthCreates a real depth map from the canvas image into the depth layer.
Canvas to DepthCopies the canvas picture into the depth layer as-is (no extraction).
Depth to CanvasCopies the depth layer back onto the canvas.
Mask to CanvasCopies the mask onto the canvas so you can see or save it as a normal image. Only works for masks the Pipeline made itself this run (Foreground/Background/Body/Ask), not file-loaded masks.
JSON PoseLoads an OpenPose skeleton (joint-coordinates JSON, copied out of Draw Things' pose layer, or a #pose shortcut) as the pose control. Sticking point: the pose's recorded width/height must match your render size.

Loop & Flow

InstructionWhat it does
NoteA comment for humans. Exported, but the Pipeline ignores it. Put your project explanation in the first Note — the sample projects all do.
ApprovePauses the run. Shows the current bucket in an editable text box; whatever you leave in the box is the bucket going forward. Belongs after an Interrogate or Enhance.
Add PipelineEmbeds another exported .txt instruction file as one item; at export, its instructions are spliced in seamlessly — for reusable chunks like a standard canvas-prep routine. Browser safety catch: after saving and reloading a project, you must click each Add Pipeline item and re-pick its file, or the export carries a warning instead of the instructions.
Loop / End LoopEverything between them repeats Loop Count times. Start Index sets the number the first saved file gets. Loops cannot nest, but several separate loops in a row are fine. See Wildcards, Sweeps & Loops.
Load Image ⓘLoop-only: each pass loads the next image from a Pictures folder. Files sort by a leading number before an underscore (12_photo.png) if present, otherwise alphabetically; the sequence cycles if the loop outlasts the folder.
Save Image ⓘLoop-only: saves each pass as name_001.png, name_002.png, … counting from Start Index.

Instructions with no Editor button

Three instructions exist in the Pipeline but can't be added from the Editor — they're leftovers or hand-edit-only features. You'd only meet them in a hand-written export:

InstructionWhat it does
Ask MaskAsks the answer model for a rectangle and fills it white as the mask. An empty mask results if the model's answer can't be parsed.
Extract PoseExtracts a pose from the canvas image into the pose layer.
Moodboard Load (legacy)Older version of Canvas to MB that also clears the canvas afterward. Replaced by Canvas to MB — don't confuse the two.
