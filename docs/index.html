Storyflow Documentation

Storyflow is a two-part automation tool for Draw Things. You build a list of instructions in a web page (the Editor), export it, and a script inside Draw Things (the Pipeline) carries the instructions out one at a time — building prompts, changing settings, moving the canvas, and rendering for you.

This wiki explains every feature in plain language: what it does, when you'd use it, and the quirks the original documentation didn't mention. It covers the Tim Edition — a fork of wetcircuit's Storyflow 261101 with several bug fixes. The original tool and videos are by Cutscene Artist (wetcircuit).

The 60-second version

  1. Build a list of instructions in the Editor (or load a sample project).
  2. Save Project (your editable source file) and Export to Pipeline / Clipboard.
  3. In Draw Things, run the StoryflowPipeline script and paste the export into the first popup.
  4. Read the Preflight Check, pick an answer model if asked, and press Start Pipeline.
  5. The Pipeline walks your list top to bottom. A Prompt instruction is what actually renders — everything before it is preparation.
